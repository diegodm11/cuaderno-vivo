Hola. Soy Alba, una profesora virtual creada con inteligencia artificial para enseñarte cómo funciona Cuaderno Vivo. Esta es una simulación: no soy una persona real y los datos que verás son de demostración.

Primero entro en Crear actividad. Selecciono Matemáticas, quinto de Primaria, el tema Fracciones y una clase de veinticuatro alumnos. La aplicación prepara ocho preguntas y las habilidades que quiero comprobar. Yo reviso el contenido y pulso Crear las fichas.

Cuaderno Vivo genera una ficha para cada alumno. Cada una utiliza un código seudónimo y un QR que solo identifica la actividad, la versión y el código del alumno. No contiene nombres, notas ni correos. Imprimo las fichas y la clase responde con lápiz y papel.

Después, desde el dispositivo docente, fotografío las fichas. En este prototipo el reconocimiento está simulado. Las respuestas estructuradas se organizan automáticamente, pero cualquier marca poco clara pasa a Revisar dudas. Aquí confirmo la respuesta; la decisión final siempre es mía.

Con las respuestas validadas, Cuaderno Vivo muestra qué habilidades domina la clase y dónde se repite un error. En este ejemplo, seis alumnos suman numeradores y denominadores. Creo un grupo flexible y preparo un refuerzo específico o una clase activa sin pantallas para el alumnado.

Finalmente, la aplicación genera una segunda actividad con preguntas diferentes sobre la misma habilidad. Al comparar los resultados, puedo comprobar si la intervención produjo una mejora inmediata y decidir si necesito revisar la retención más adelante.

Así se cierra el ciclo: papel, revisión docente, diagnóstico, refuerzo y evidencia de mejora. Ahora puedes probar tú mismo el recorrido guiado dentro de Cuaderno Vivo.
