Alba: Hola. Soy Alba, una profesora virtual creada con inteligencia artificial para enseñarte cómo funciona Cuaderno Vivo. Esta es una simulación: no soy una persona real y los datos que verás son de demostración.

Primero entro en Crear actividad. Selecciono Matemáticas, quinto de Primaria, el tema Fracciones y una clase de veinticuatro alumnos. La aplicación prepara ocho preguntas y las habilidades que quiero comprobar.

Cuaderno Vivo genera una ficha para cada alumno. Cada ficha utiliza un código seudónimo y un QR que no contiene nombres, notas ni correos. La clase responde con lápiz y papel.

Después fotografío las fichas. En este prototipo el reconocimiento está simulado. Cualquier marca poco clara pasa a revisión y la decisión final siempre es docente.

Con las respuestas validadas, la aplicación muestra qué habilidades domina la clase y dónde se repite un error. Preparo un refuerzo específico y una segunda actividad para comprobar la mejora.

Así se cierra el ciclo: papel, revisión docente, diagnóstico, refuerzo y evidencia de mejora.

PRIVACIDAD Y DATOS

Privacidad por diseño, visible para el profesor

La promesa no basta: el usuario debe saber qué existe, dónde está y cómo eliminarlo.

01

Identidad mínima

Las fichas usan A01–A24. Son códigos seudónimos, no anónimos, si el centro conserva una relación externa con nombres.

Activo
02

Procesamiento local

Actividad, respuestas, revisiones, refuerzo y resultado se guardan en el almacenamiento local de este navegador. No existe backend ni sincronización automática.

Activo
03

Imágenes temporales

La fotografía se procesa en memoria y su URL temporal se revoca al confirmar la revisión. No se incluye en la exportación.

Activo
04

Control y borrado

La exportación refleja las claves locales existentes. El borrado elimina perfil, actividad, resultados, onboarding y cachés de Cuaderno Vivo.
